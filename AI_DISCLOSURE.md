# AI use (Nexus tag: AI Assisted)

Vitals was written with AI help (Anthropic Claude) as part of the Defib project.
Claude wrote the C++ source, build files and Python tools; a human chooses what ships, makes the release
decisions and does the in-game testing on their own PC. Testing covers the game builds and mod managers that
person has installed, not every build the plugin lists. Not every change has had an in-game test before a release.

# AI use (Nexus tag: AI Assisted)

Vitals was written with AI help (Anthropic Claude) as part of the Defib project.
Claude wrote the C++ source, build files and Python tools; a human chooses what ships,
runs every in-game test and makes release decisions. Every release lists the exact game
builds it was tested on. 1.10.984 (Next-Gen) is built for but not tested.
